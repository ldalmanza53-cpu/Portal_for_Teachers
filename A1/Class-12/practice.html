GRAMMAR PLUS 1 SB-195

🔤 Demonstratives & Pronouns

Learn how to use this, that, these, those and one / ones.

Singular Nouns (1 item) one
  • THIS (Nearby): "How much is this hat here?"
  • THAT (Far away): "How much is that hat over there?"
  • Use one to replace a singular noun: "I like the red one."
Plural Nouns (2+ items) ones
  • THESE (Nearby): "How much are these earrings here?"
  • THOSE (Far away): "How much are those earrings over there?"
  • Use ones to replace plural nouns: "I like the green ones."

GRAMMAR PLUS 2 Comparisons with Adjectives

📈 Comparative Adjectives

Learn how to compare items in English using -er and more + adjective.

Short Adjectives (1-2 syllables)

Add -er to short words or change -y to -ier.

• cheap ➔ cheaper

• nice ➔ nicer

• big ➔ bigger (double consonant)

• pretty ➔ prettier (-y ➔ -ier)

Long Adjectives (2+ syllables)

Use more + adjective for longer words.

• stylish ➔ more stylish

• expensive ➔ more expensive

• attractive ➔ more attractive
