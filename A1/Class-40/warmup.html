Essential Verb Cheat Sheet

1. Use BE (is / are) Height & Build

Use for general size, age, height, and build features.

✓ "He is tall and slim."
2. Use HAVE / HAS GOT Hair & Eyes

Use for hair color/length, eyes, facial hair, and freckles.

✓ "She has got blue eyes."
3. Use WEAR / WEARS Accessories

Use for removable items like glasses, sunglasses, hats, clothes.

✓ "He wears black glasses."
