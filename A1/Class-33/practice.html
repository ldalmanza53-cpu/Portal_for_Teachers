Count Nouns (Plural / Can count)

Questions: How many...? / Are there many...?

Answers: a lot / a few / many (e.g., apartment buildings, drugstores, parks)

Noncount Nouns (Singular / Cannot count)

Questions: How much...? / Is there much...?

Answers: a lot / a little / much (e.g., traffic, noise, pollution, crime)
