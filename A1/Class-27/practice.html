Mandatory A1 Grammar Constraints:
  • Must use Present Continuous (is/are + -ing).

1. Quantifiers (0% - 100%)
  • 100%: All / Nearly all
  • 75%-90%: Most / Many / A lot of
  • 50%: Some
  • 10%-25%: Not many / Few
  • 0%: No one
2. Frequency & Routines
  • Adverbs: always, usually, often, sometimes, hardly ever, never
  • Expressions: every day, once a week, twice a month, three times a year
  • Note: "Usually" and "Sometimes" can start a sentence.
3. Present Continuous

Actions happening right now:

Subj + am/is/are + Verb-ing e.g., She is studying. They are cooking.
4. Questions with How
  • How often? -> Every day / Twice a week
  • How long? -> Thirty minutes / An hour
  • How well? -> Pretty well / Not very well
  • How good? -> Pretty good / OK / Not so good
