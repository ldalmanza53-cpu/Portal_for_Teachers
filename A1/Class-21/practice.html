Grammar Reference

1. Present Continuous

Talk about actions that are happening now or these days.

Action Happening Now

Form: present of be + -ing

"What are you doing these days? I'm studying English."

Drop final -e

For verbs ending in -e, drop -e and add -ing:

have → having | live → living

Double Consonant

For vowel + consonant, double consonant + -ing:

sit → sitting | swim → swimming

Grammar Reference

2. Quantifiers

Use quantifiers to talk about proportions and approximate amounts.

100% All 98% Nearly all 89% A lot of 5% Few 0% No one

Plural Noun Quantifiers

Use a lot of / all / few / nearly all before plural nouns:

"A lot of / All / Few / Nearly all families are small."

Special Rule: "No one"

Use no one directly before a singular verb:

"No one gets married before the age of 18."
