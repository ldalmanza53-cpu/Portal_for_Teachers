Indirect Messages (Statements)

Use tell + object + that to pass along information or statements.

Formula:

Could you tell [person] that + [clause]?

Example:

"Could you tell Sarah that the party starts at 8:00?"

Indirect Requests (Imperatives)

Use ask + object + to + verb when requesting someone to do something.

Formula:

Would you ask [person] to + [verb]?

Example:

"Would you ask Alex to buy different types of snack food?"

Negative Indirect Requests

Place not before the infinitive to + verb for negative requests.

Formula:

Please ask [person] not to + [verb]

Example:

"Please ask the DJ not to play loud rock music late."
