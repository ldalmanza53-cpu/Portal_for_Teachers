Grammar Rules: Advice with Should & Shouldn't

SHOULD (Affirmative Advice)

Use should to state that something is a good idea, beneficial, or sensible.

Subject + should + Base Verb
"You should learn local words."
SHOULDN'T (Negative Advice)

Use shouldn't (should not) to advise against bad, risky, or unhelpful actions.

Subject + shouldn't + Base Verb
"You shouldn't carry lots of cash."

💡 Key Tip:

Always use the base form of the verb after should or shouldn't (no "to", no "-ing", no "-ed").

✓ You should learn (NOT: You should to learn)
