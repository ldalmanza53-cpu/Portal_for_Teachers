Unit 4 Grammar Reference Guide

Review these 3 essential grammar points from Interchange SB page 196 before starting the exercises!

1

Simple Present Questions

Do + I/you/we/they + base verb

Do you like rock?
➜ Yes, I do. / No, I don't.

Does + he/she/it + base verb

Does she like rock?
➜ Yes, she does. / No, she doesn't.

Warning:

Don't add -s to the base verb in questions!

Does she likes rock? ❌
Does she like rock? ✅
2

Object Pronouns

Subject pronouns go before the verb. Object pronouns go after verbs or prepositions.

Subject Object
Ime
youyou
hehim
sheher
itit
weus
theythem
3

Would; verb + to + verb

Inviting / Offering:

Would you like to go to the game?

Affirmative Short Answer:

Yes, I would.

Rule Note:

Don't use contractions in affirmative short answers!

Yes, I'd. ❌
Yes, I would. ✅
