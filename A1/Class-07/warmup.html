Third Person (-s / -es) Rule

Subject is He / She, so we add -s to the verb (start ➔ starts).

Preposition Rule

Grammar Tip: Wh- Questions

When asking about schedules in 3rd person singular (He/She):

Where + does + he/she + work?

What time + does + he/she + start?

When + does + he/she + go home?

Verb Ending Rules (-s / -es)

  • Most verbs: add -s (works, starts, cooks)
  • Verbs ending in -ch, -sh, -o, -x: add -es (teaches, finishes, goes)
  • Verbs ending in consonant + y: change to -ies (studies, flies)
