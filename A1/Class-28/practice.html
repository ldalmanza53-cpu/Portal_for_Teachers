Mandatory A1 Simple Past Constraints:
  • Must use a regular simple past verb (-ed / -d / -ied).

1. Common Irregular Verbs (V1 -> V2)
  • go -> went
  • see -> saw
  • buy -> bought
  • eat -> ate
  • drink -> drank
  • have -> had
  • do -> did
  • take -> took
2. Regular Verb Spelling
  • Most verbs: add -ed (walk -> walked)
  • Ends in -e: add -d (like -> liked)
  • Consonant + y: change y to -ied (study -> studied)
  • CVC (stressed): double final consonant (stop -> stopped)
3. Sentence Formulas
Affirmative: Subj + V2 + ...
Negative: Subj + didn't + V1 (base)
Questions: Did + Subj + V1 (base)?
