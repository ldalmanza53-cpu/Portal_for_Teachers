Grammar Concept

Expressions of Quantity

Learn how to talk about city problems using count nouns (things you can count like cars, parks) and noncount nouns (things you cannot count like pollution, traffic).

1, 2, 3

With Count Nouns

Plural nouns (e.g. cars, streetlights, parks)

Countable
  • too many

    There are too many cars.

  • fewer

    There should be fewer cars.

  • more

    We need more streetlights.

  • aren't enough

    There aren't enough police officers.

With Noncount Nouns

Singular/Mass nouns (e.g. pollution, noise, parking)

Uncountable
  • too much

    There is too much pollution.

  • less

    There should be less pollution.

  • more

    We need more public transportation.

  • isn't enough

    There isn't enough parking.

Quick Golden Rule to Remember:

Use FEWER and TOO MANY with count nouns (plural ends in -s).
Use LESS and TOO MUCH with noncount nouns. MORE works for both!
