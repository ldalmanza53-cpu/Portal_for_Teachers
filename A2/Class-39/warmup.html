📘 First Conditional Formula & Rules

Use the First Conditional to talk about real future possibilities or consequences based on a condition.

Standard Pattern: If + Present Simple, ... WILL + Base Verb

"If it rains tomorrow, we will stay inside."

Reversed Clause Pattern: WILL + Base Verb ... if + Present Simple

"We will stay inside if it rains tomorrow."
