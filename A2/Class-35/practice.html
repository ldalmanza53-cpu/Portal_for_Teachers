Relative Clauses of Time • VRB-91

Describing an Event with when

Aprende a describir tradiciones y festividades comenzando con Thanksgiving is a time when...

💡 Guía Gramatical: Cláusulas Relativas de Tiempo

1. Estructura con a time when: Para describir eventos, celebraciones o fechas especiales:

• [Evento/Festividad] + is a time when + [Sujeto + Verbo + Complemento]

• Thanksgiving is a time when families get together.
2. Concordancia Verbal: El verbo dentro de la cláusula mantiene su conjugación original en presente simple.

• Joe helps with the clean-up.
$\rightarrow$ Thanksgiving is a time when Joe helps with the clean-up.
