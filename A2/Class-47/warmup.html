Expressing Unchangeable Past Events

When discussing the past, we cannot change what already happened. We use specific grammatical structures to express **regret**, **criticism**, or **hypothetical alternative outcomes**.

1. Third Conditional

Hypothetical Past Result

Used to imagine a different outcome for an event that already happened in the past.

Formula:
If + Past Perfect [had + V3], ... would / could / might have + V3
Example Breakdown

If I had set my alarm,

I wouldn't have missed the flight.

(Reality: I didn't set my alarm, so I missed the flight.)

2. Wish / If Only

Direct Past Regret

Expresses strong sadness or desire that a past fact had been different.

Formula:
Wish / If only + Subject + Past Perfect [had / hadn't + V3]
Example Breakdown

I wish I had saved my essay.

If only I hadn't spent all my money!

(Reality: I didn't save my essay; I spent all my money.)

3. Should Have

Past Criticism & Advice

Used to criticize past actions or offer advice after the fact.

Formula:
Subject + should / shouldn't have + Past Participle [V3]
Example Breakdown

You should have checked the weather.

I shouldn't have eaten that street food.

(Reality: You didn't check weather; I ate bad street food.)
