Sentence Structure Shift

Active Voice:
Subject + Past Verb + Object
e.g., Walt Disney opened Disneyland in 1955.
Passive Voice with 'by':
Object + was / were + Past Participle + by + Subject
e.g., Disneyland was opened by Walt Disney in 1955.

Choosing "was" or "were"

WAS

Use with Singular Nouns / He / She / It

"The film was directed..."

WERE

Use with Plural Nouns / You / We / They

"The songs were recorded..."

Key Irregular Past Participles to Remember:
write → written win → won see → seen give → given choose → chosen build → built
