A2 Grammar Focus: Explaining Uses & Purposes

Learn 5 essential structures to describe why objects exist, how they help us, and what they enable us to do!

1. Infinitive
used to + base verb

"It is used to track lost keys."

2. Preposition
used for + V-ing

"It is used for translating languages."

3. Enabling Verbs
allows / enables to

"It enables you to charge anywhere."

4. Relative Clause
a gadget that / which

"It is a device that measures water."

5. Result Clause
so that + subject + can

"...so that you can work without noise."
