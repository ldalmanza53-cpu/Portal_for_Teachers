Rule 1: Unreal Conditional Sentences with If Clauses
Formula: If + Simple Past, Would + Base Verb

The clauses in unreal conditional sentences can come in either order. Don't use a comma when the if clause comes second.

If clause first (use comma): "If I won the lottery, I'd share the money."
Main clause first (no comma): "I'd share the money if I won the lottery."

Rule 2: Past Modals (should have / would have)
Formula: Modal + have + Past Participle

Use should have and would have for all subjects. They do NOT change form!

✨ Example: "He should have called sooner." (NOT: He should has called)
