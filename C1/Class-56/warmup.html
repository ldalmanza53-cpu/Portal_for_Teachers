Discourse & Persuasion Matrix

Upgrade simple A2 opinions into sophisticated B1+ persuasive structures using discourse arcs and concession-rebuttal sandwiches.

1

The Persuasive Essay Arc

[Hook/Topic] → [Main Stance] → [Addition] → [Concession] → [Conclusion]

Builds a logical paragraph progression from introduction to resolution.

"First and foremost, digital chat is fast. Furthermore, it saves records..."

2

Discourse Marker Placement

[Discourse Marker], + [Full Clause]

Always place formal markers at the start of sentences followed by a comma.

"However, subtle emotions are lost in text. Consequently, misunderstandings happen."

3

Concession-Rebuttal Sandwich

Admittedly [Counterpoint]; however, [Rebuttal/Stronger Point]

Demonstrates maturity by acknowledging opposing views before refuting them.

"Admittedly, AI speeds up drafting; however, human empathy remains crucial."

🚀A2 Basic Opinions vs B1+ Persuasive Upgrades

Compare basic statements with upgraded persuasive sentences using discourse markers.

BASIC (CEFR A2) Simple Contrast

"Digital chat is fast. Face-to-face is better for problems."

UPGRADED (CEFR B1+) First & Foremost + However

"First and foremost, digital messaging provides speed; however, face-to-face interaction remains vital for conflict resolution."

BASIC (CEFR A2) Simple Addition

"AI tools write emails fast. People lose connection."

UPGRADED (CEFR B1+) Furthermore + In spite of this

"AI tools boost writing speed; furthermore, they reduce drafting time. In spite of this, personal connection must not be sacrificed."

BASIC (CEFR A2) Simple Cause

"Active listening is important. Teams work better."

UPGRADED (CEFR B1+) Due to the fact that + Consequently

"Due to the fact that active listening fosters trust, teams communicate effectively; consequently, productivity rises."

BASIC (CEFR A2) Simple Concession

"Social media is fun. It causes privacy issues."

UPGRADED (CEFR B1+) Admittedly + Therefore

"Admittedly, social media encourages global connectivity; therefore, users must maintain transparency and caution."
