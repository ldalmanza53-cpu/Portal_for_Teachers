Grammar Plus: Phrasal Verbs Reference Vault

Explore rules for Separable, Inseparable, Intransitive, and Three-word Phrasal Verbs.

Separable Phrasal Verbs

Object moves

Can take objects before or after the particle. If the object is a pronoun (him, her, it, them), it must go between the verb and particle!

{{ pv.verb }}

Inseparable Phrasal Verbs

Cannot split

The object cannot go between the verb and particle. It always follows the complete phrasal verb.

{{ pv.verb }}

Intransitive Phrasal Verbs

No direct object

These verbs do not take direct objects (e.g. "She didn't show up").

{{ pv.verb }}

Intransitive + Preposition

3-word combo

Certain intransitive verbs take an object when followed by a preposition (e.g. back down from).

{{ pv.verb }}
