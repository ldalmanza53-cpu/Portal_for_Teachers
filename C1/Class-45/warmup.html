Grammar Architecture

Object Order Matrix & Dative Alternation Rules

In English, verbs of transfer or creation can take both a Direct Object (what is given/made) and an Indirect Object (who receives it). Learn the rules below to avoid common B1 learner errors.

1

Pattern A: Direct Recipient (No Preposition)

Verb + Indirect Object + Direct Object

Place the recipient immediately after the verb. Do NOT use "to" or "for"!

✔️ She offered clients a 20% discount.

❌ She offered to clients a 20% discount.

2

Pattern B: Prepositional Transfer ("TO")

Verb + Direct Object + TO + Indirect Object

Used with verbs of transfer: give, send, offer, show, tell, pass, hand, lend, promise.

✔️ We sent the promo code to all subscribers.

Action transfers the object towards the recipient.

3

Pattern B: Creation / Benefactive ("FOR")

Verb + Direct Object + FOR + Indirect Object

Used with verbs of creation or preparing: buy, find, order, design, make, choose, save.

✔️ The team designed a new campaign for the client.

❌ The team designed a new campaign to the client.

4

The Mandatory Pronoun Swap Rule!

If Direct Object is a pronoun (it / them) → MUST use Pattern B!

When both objects are pronouns, standard English requires: "Verb + it/them + to/for + me/you/him/her/us/them".

✔️ Give it to me.

❌ Give me it. (Non-standard in standard written B1 English)
