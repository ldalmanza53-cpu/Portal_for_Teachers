Language Structure Engine

Passive Voice & Useful Evaluation Expressions

Shift focus from the action performer to the communicator quality or action itself!

1. Present Simple Passive
Object + IS / ARE + Past Participle (V3)
  • • Active listening is regarded as vital.
  • • Non-verbal cues are noticed immediately.
  • • Clear goals are communicated daily.
2. Modal Passive
Object + CAN / SHOULD / MUST + BE + V3
  • • Vocal clarity can be enhanced by practice.
  • • Misunderstandings should be avoided.
  • • Respect must be shown to all members.
3. Reporting Passives
Subject + IS CONSIDERED / EXPECTED TO...
  • • Leaders are expected to be empathetic.
  • • Brevity is considered to be effective.
  • • Integrity is valued in negotiations.
4. Evaluation Connectors
IS DEMONSTRATED WHEN / SHOWN THROUGH...
  • • Competence is demonstrated when...
  • • Trust is built through open dialogue.
  • • Authority is conveyed via posture.
