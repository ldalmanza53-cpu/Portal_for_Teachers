Grammar Explorer • Page T-41

Such... that and So... that

Use so, such, so many / few, and so much / little to express extremes in exclamatory sentences.

Rule A: Such + Noun Phrase Noun Focus

such is followed by a noun (usually modified by an adjective) + that.

• It's such a great show that I bought all eight seasons.
Rule B: So + Adjective / Adverb Adjective Focus

so is followed by an adjective or adverb + that.

• Dr. House is so foul-tempered that I hated him.
Rule C: Countable Quantifiers So many / So few

so many and so few are followed by plural countable nouns.

• Packed with so many jokes that it's nonstop laughs.
Rule D: Uncountable Quantifiers So much / So little

so much and so little are followed by uncountable nouns.

• Leaves me so little TV time that I don't want to waste it.
