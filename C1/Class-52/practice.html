Noun Clauses with Whoever & Whatever

Noun clauses begin with whoever or whatever and can function as either the subject or object of the main clause or preposition.

Whoever

= the person who / anyone who / everyone who

Subject Function inside clause:

"Whoever applies should have at least five years of experience."

Object Function / Preposition object:

"Extra consideration will be given to whoever can start immediately."

Whatever

= anything that / everything that

Subject Function inside clause:

"Be ready to do whatever is required to return injured animals."

Object Function inside clause:

"You'll find whatever you need to start a career in nature right here!"
