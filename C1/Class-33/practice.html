Grammar Focus Reference: Double Comparatives

Structure: The + comparative expression..., the + comparative expression...

Clause 1 (Condition / Cause) Clause 2 (Result / Effect) Type
The harder you work, the more successful you become. Adjective / Adverb
The more you read, the smarter you get. Verb / Adjective
The higher we climb, the colder it feels. Adjective (-er)
The less money you waste, the more you save. Noun / Quantifier

Rules & Tips

  • Structure: Both halves of the sentence must start with the.
  • Short Adjectives: Add -er (e.g., the colder, the faster).
  • Long Adjectives: Use more/less (e.g., the more expensive).
  • Irregulars: good → better, bad → worse.
