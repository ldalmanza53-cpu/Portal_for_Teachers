Grammar Reference Box

Emphatic Stress in Conversation

In speech, so and such are often used alone without that clauses for emphasis.

"The host is so funny!"

"That was such a great documentary!"

Quantifiers

Use so much / so little (uncountable) and so many / so few (countable) for emphasis.

"There are so many shows!"

"Gives away so much money!"

Adverbial Usage

much (=frequently) and little (=infrequently) can follow so as adverbs.

"Why do you watch TV so much?"

"Featured so little..."

Pronoun Function

Much, little, many, few serve as pronouns replacing omitted nouns.

"I watch so much (TV)."

"There are so few (reporters)."
