Grammar Rule Reference • Page T-63

Placement of Direct and Indirect Objects

Flexible Verbs (Pattern A & B)

Verbs: get, give, lend, offer, sell, send, show, teach, tell

A: send info to shoppers
B: send shoppers info
Pattern A ONLY (DO + to/for + IO)

Verbs: announce, describe, explain, mention, provide, recommend, return, say

A: explain it to me
❌ explain me it
Pattern B ONLY (IO + DO)

Verbs: allow, ask, cause, cost (NO preposition!)

B: cost him two dollars
❌ cost two dollars to him
CRITICAL PRONOUN RULE (Pronoun Direct Objects: 'it' / 'them')

When the direct object is a pronoun (e.g. it or them), flexible verbs MUST follow Pattern A. You cannot put a pronoun direct object after an indirect object pronoun.

✅ Send it to them (Pattern A) ❌ Send them it (Invalid Pattern B)
