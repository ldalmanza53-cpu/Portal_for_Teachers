Describing Problems 2: Solutions & Ongoing Issues

When an item is broken, dirty, or malfunctioning, we use Need + Gerund or Need + Passive Infinitive to describe what action is required. We use Keep + Gerund to describe annoying, repetitive problems!

Pattern 1: Active Gerund

Need + Gerund (-ing)

Subject + need / needs + Verb-ing

Expresses an action that must be performed on the subject. Simple and conversational!

• "The oven needs adjusting."
• "The alarm needs fixing."
• "The plants need watering."
Pattern 2: Passive Infinitive

Need + Passive Infinitive

Subject + need(s) + to be + Past Participle

Same exact meaning as Pattern 1! Emphasizes the passive state of the required repair.

• "It needs to be adjusted."
• "It needs to be fixed."
• "They need to be watered."
Pattern 3: Recurring Issue

Keep + Gerund (-ing)

Subject + keep / keeps + Verb-ing

Describes a problem that repeats again and again without stopping or causing annoyance.

• "Everything keeps burning."
• "The alarm keeps going off."
• "The door keeps squeaking."
