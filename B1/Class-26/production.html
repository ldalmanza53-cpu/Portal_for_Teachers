B1 Complaint Language Toolkit

1. Polite Complaint Openers

• Excuse me, I'm afraid there's a problem with my...

• I'm sorry to bother you, but my order has a defect.

• I was wondering if you could help me with an issue regarding...

• I'd like to make a formal complaint about...

2. Describing Defects & Malfunctions

• The screen is cracked / scratched.

• There is a stain / tear / leak / dent on the item.

• The device won't turn on / won't charge.

• The system keeps freezing / keeps disconnecting.

3. Demanding Resolutions

• I would like a full refund, please.

• Would it be possible to exchange this for a new one?

• Could you please send a technician to fix it?

• I insist on speaking to the store manager.

Sample Dialogue Model

Customer: "Excuse me, I'm afraid there's a problem with room 302. The AC is leaking and the Wi-Fi keeps disconnecting."

Officer: "I'm so sorry to hear that! Would you prefer a full room transfer or should I send a repair technician immediately?"
