Describing Repairs Required for Problem Items

When something is damaged, broken, or dirty, you can express the necessary solution in two grammatically equivalent ways using need. Both forms carry the same meaning!

Structure 1: Gerund

Subject + need / needs + Verb-ing

Use a gerund (-ing form of the verb) directly after the verb need.

Examples:

• The heat needs adjusting. (heat = singular)

• The rooms need cleaning. (rooms = plural)

• The chair needs fixing. (chair = singular)

Structure 2: Passive Infinitive

Subject + need / needs + to be + Past Participle

Use to be followed by the Past Participle (e.g., adjusted, cleaned, emptied, fixed, repaired, washed).

Examples:

• The heat needs to be adjusted. (heat = singular)

• The rooms need to be cleaned. (rooms = plural)

• The chair needs to be fixed. (chair = singular)

Crucial Grammar Guardrail: Subject-Verb Agreement (-s vs. no -s)
Singular Subject → NEEDS (with -s)

• The wastebasket needs emptying.

• The hair dryer needs to be repaired.

(Singular nouns: heat, wastebasket, chair, hair dryer, room, wall)

Plural Subject → NEED (NO -s)

• The rooms need cleaning. (NOT "needs")

• The floors need to be washed. (NOT "needs")

(Plural nouns end in -s: rooms, floors, windows, chairs, walls)
