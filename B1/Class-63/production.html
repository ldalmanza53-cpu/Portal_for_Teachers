B1-B2 Integrated Language Toolkit

1. Past Speculation (Modals)

• They must have overlooked the error (High certainty).

• It couldn't / can't have crashed by itself (Impossibility).

• Malware might / could have caused it (Possibility).

✗ Never use "mustn't have" for deduction.

2. Process SOPs & Causatives

• is / are + V3: "Data is processed and stored."

• have + person + V1: "We have IT scan the servers."

• get + person + to + V1: "We get staff to audit logs."

3. Essential Relative Info

• Engineers who hold AWS certificates advance.

• Applicants whose portfolios feature UX win.

✓ No commas! Defines essential criteria.

4. Extra Info Relative Clauses

• Dr. Vance, who led threat detection, arrived.

• Ms. Clara, whose team patched the bug, spoke.

✗ Always use commas; never use "that".
