B1-B2 WorkCraft Language Toolkit

1. Passives for Objective SOPs

• is / are + V3: "Files are audited every Friday."

• must be + V3: "Credentials must be verified first."

2. Causative Delegation

• have + person + V1: "We have QA test the code."

• get + person + to + V1: "We get legal to review contracts."

• have + object + V3: "We have server logs audited."

3. Essential Relative Clauses

• Candidates who hold AWS certification will advance.

• The tool that processes metrics was updated.

✓ No commas! Defines essential eligibility.

4. Extra Info Relative Clauses

• Dr. Vance, who led Q3 audit, hosts the panel.

• Ms. Gupta, whose firm manages security, arrived.

✗ Always use commas; never use "that".
