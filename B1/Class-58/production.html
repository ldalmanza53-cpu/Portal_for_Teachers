B1-B2 Past Narrative Toolkit

1. Tense Layering

• Past Continuous: Background action ("While we were reviewing code...")

• Past Simple: Interruption / Main event ("...the alert sounded.")

• Past Perfect: Prior completed action ("...because an error had occurred.")

2. Sequence Linkers

• Prior to + N/-ing: "Prior to launching the service..."

• By the time + Simple Past: "By the time help arrived..."

• Subsequently: "Subsequently, the system restarted."

3. Causal & Result Links

• on account of + noun: "...on account of server failure."

• resulting in + gerund: "...resulting in a long outage."

4. Narrative Vocabulary

• Catalyst: Event that precipitates change.

• Aftermath: Period following a major incident.

• Milestone: Significant stage or achievement.
