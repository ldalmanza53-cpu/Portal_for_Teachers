Third Conditional Rule Summary

Use the Third Conditional to talk about imaginary situations in the past that did not happen.


Clause Grammar Structure Example
If Clause (Condition) If + Past Perfect (`had` / `hadn't` + V3) If I had studied harder,
Main Clause (Result) would have / wouldn't have + V3 I would have passed the test.

⚠️ Common Trap: Do not use would have inside the If clause!
• Incorrect: If I would have known...
• Correct: If I had known...
