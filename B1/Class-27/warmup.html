How to Describe Customs in English

Combine prepositions of place/time with infinitive structures to describe traditional habits clearly.

Preposition IN Countries / Cities "In India..." / "In Tokyo..."
Preposition DURING / ON Festivals / Specific Days "During Diwali..." / "On New Year's Eve..."
Custom Structure It is a custom to + Verb "It is a custom to light lamps."
