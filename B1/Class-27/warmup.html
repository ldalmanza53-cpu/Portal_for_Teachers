Core Language Framework

1

Feelings & Emotions (-ed vs -ing)

Internal feeling vs. External cause

Internal (-ed): "I feel disappointed / frustrated / overwhelmed."

External (-ing): "The slow service was disappointing / frustrating."

2

Unmet Expectations

Expected [Noun] + to be [Adjective]

Infinitive Target: "I expected the delivery to be fast."

Assumption Gap: "We assumed that the hotel room would be clean."

3

Problems & Complaints

Stating the core issue clearly

Core Issue: "The main problem is that the software crashes."

Unsatisfied: "I am dissatisfied with the response time."

4

Proposed Improvements

Needs to be + Past Participle (V3)

Passive Need: "The wifi network needs to be upgraded."

Action Modal: "Management should hire additional staff."
