Unit 6 Grammar Reference

Describing Problems & Haggling Cheat Sheet

Master noun vs. adjective problem forms, need structures, keep + gerund, and essential bargaining expressions.

1. Adjective vs. Noun Forms

You can describe physical defects using either an adjective (with be) or a noun (with have/has):

• Adjective: The windshield is cracked. / The seat is torn.

• Noun: The windshield has a crack. / The seat has a tear.

• Adjective: The body is dented. / The radiator is leaking.

• Noun: The body has a dent. / The radiator has a leak.

2. Need + Gerund / Passive Infinitive

To state what repair action is required, both forms are grammatically identical:

• Need + Gerund (-ing): The Wi-Fi needs improving.

• Need + Passive Infinitive: The Wi-Fi needs to be improved.

• Plural Subject Agreement: The chairs need replacing / need to be replaced. (NO -s on need!)

3. Keep + Gerund (Repeated Events)

Use keep / keeps + verb-ing to describe an annoying problem that happens continuously or repeatedly:

• The Wi-Fi connection keeps disconnecting.

• The radiator keeps leaking coolant.

• The classroom projector keeps shutting off automatically.

4. Haggling & Excuses Language

Essential conversational building blocks from Page 43:

• Buyer: "I'm interested in this car, but [part] is [defect]. I'll give you $[amount] for it."

• Seller Excuse: "That's no big deal. You can fix that easily."

• Seller Excuse: "You can't really see that." / "It's barely noticeable."

• Counteroffer: "How about $[amount]?" / "I can drop the price by $[amount]."
