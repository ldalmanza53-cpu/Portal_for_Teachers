Grammar Toolkit: 3 Ways to Express Object Problems

Pattern 1: Adjective
Object + is/are + Adjective

"The phone screen is cracked."

"The clothes are stained."

Pattern 2: Noun
There is a + Noun + in/on Object

"There is a crack on the screen."

"There is a leak under the kettle."

Pattern 3: Malfunction
Object + won't + Verb

"The drawer won't open."

"The battery won't charge."
