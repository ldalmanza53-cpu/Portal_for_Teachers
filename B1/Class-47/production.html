B1-B2 Regret Toolkit

1. Third Conditional (Unreal Past)

• If I had known, I would have accepted.

• If we hadn't missed the deadline, we wouldn't have lost the account.

2. Direct Past Regrets

• We should have hired a senior consultant.

• I shouldn't have ignored the contract terms.

3. Wishes & If Only

• I wish I had saved more money in my twenties.

• If only we had verified the supplier beforehand.

Sample Dialogue Model

Analyst: "In 2023, our firm launched an app without beta testing. We should have run a full QA audit. If we had tested it, we wouldn't have suffered negative user reviews."

Evaluator: "Clear insight! If you had delayed the launch by two weeks, what extra costs would you have incurred?"
