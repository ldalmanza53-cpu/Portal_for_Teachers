Grammar Rule Highlight

Indefinite Articles: When to use A vs. AN

• Use A before consonant sounds (a book, a phone, a desk, a marker).
• Use AN before vowel sounds (a, e, i, o, u) like an eraser, an umbrella, an ID card, an apple.

Demonstrative Pronouns Matrix

Learn how distance (Near vs. Far) and quantity (Singular 1 vs. Plural 2+) change the word.

1
NEAR + 1 (Singular) 🖐️ 📱

THIS

"This is a phone."

Use THIS when one object is close to you (here).

2
FAR + 1 (Singular) 👉 ... 📋

THAT

"That is a board."

Use THAT when one object is far from you (there).

3
NEAR + 2+ (Plural) 🖐️ 🔑🔑

THESE

"These are keys."

Use THESE when two or more objects are close to you.

4
FAR + 2+ (Plural) 👉 ... 🪑🪑

THOSE

"Those are chairs."

Use THOSE when two or more objects are far away.
