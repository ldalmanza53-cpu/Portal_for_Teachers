Grammar Focus: Passive Voice + Infinitive of Purpose

When stating the purpose of an invention, use was / were + created / invented / designed + TO + base verb.

Singular Subject: "A scanner was invented to digitize paper documents."
Plural Subject: "Laptops were designed to make working on the go easier."
