Section A: Contrast Linkers & Exception Markers Reference

1. Contrast Linkers (Connecting Clashing Ideas)

  • Whereas / While: Used to introduce a contrasting clause.
    "In the US, meetings start promptly, whereas in Colombia time is more flexible."
  • Unlike + Noun: Points out direct difference.
    "Unlike American individualists, Latin Americans prioritize group harmony."
  • On the other hand: Transition between independent sentences.
    "Americans value directness. On the other hand, indirect speech avoids offense."

2. Exception Markers (Highlighting Exclusions)

  • Except for / Apart from: Excludes specific items from a general rule.
    "All daily meetings were casual, except for the formal client interview."
  • With the exception of: Formal exception phrase.
    "With the exception of high-level executives, titles like 'Doctor' are rarely used."

[Answer: whereas / while]

[Answer: Unlike / In contrast to]

[Answer: except for / with the exception of]

[Answer: On the other hand, / Conversely,]
