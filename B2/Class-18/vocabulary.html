Definition

Order of Modifiers Example

They booked a stay in a [charming] [small] [19th-century] coastal resort town.

Pattern: Opinion → Size → Age → Type/Classification
⚠️ Order Error Warning

Placing location or classification before opinion (e.g., "a coastal charming town") is incorrect.
