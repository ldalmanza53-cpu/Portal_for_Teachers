Modifiers, OSASCOMP Order & Contrast Connectors

Intensity Modifiers Scale

Use modifiers to quantify differences between cities:

Slight / Moderate

slightly / somewhat / a bit

"Kyoto is slightly quieter."

Strong / Notable

considerably / remarkably

"Tokyo is remarkably faster."

High Intensity

exceptionally / far more

"New York is far more expensive."

Adjective Order Rule (OSASCOMP)

When combining multiple adjectives before a noun:

1. Opinioncharming
2. Sizespacious
3. Ageancient
4. Shapesquare
5. Colorgreen
6. OriginJapanese
7. Materialwooden

Contrast Connector Matrix

whereas / while Direct clause contrast: "Tokyo is vibrant, whereas Kyoto is serene."
on the other hand / in contrast to Sentence transition: "In contrast to New York, Florence is compact."
although / despite Concession: "Although Medellín is warm, Bogotá is cooler."
