B1 Past Habits Formula Matrix

1. used to + base verb

For past habits OR past states that are no longer true.

"I used to live in Madrid."

2. would + base verb

For repeated past ACTIONS only (not state verbs!).

"Every summer we would go camping."

3. didn't use to + base verb

For past negative habits (Note: no 'd' on use!).

"I didn't use to like olives."

4. Present Contrast Markers

Connect past habits with current reality.

"...but nowadays I eat them daily."

Critical B1 Guardrail: State vs Action Verbs

'Would' can NEVER be used with state verbs (e.g., be, live, have, like, love, know, own). Use 'used to' for states!

"When I was young, I would live in Paris." (INCORRECT!)
"When I was young, I used to live in Paris." (CORRECT!)
