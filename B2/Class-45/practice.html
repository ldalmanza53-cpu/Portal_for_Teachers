Grammar Plus 7 • Decision Rules

Active vs. Passive Decision Matrix

Learn when to emphasize the agent (Active) vs. when the agent is unknown, obvious, or unnecessary (Passive).

Rule Focus: Is the agent (doer) important, unknown, or obvious?
1. Agent Unknown / Obvious -> PASSIVE

If the person/thing doing the action is unknown or obvious from context, use the passive voice.

"The spyware is being used to collect information."
(Agent is unknown)
2. Agent Emphasized -> ACTIVE

If the person or entity performing the action needs special emphasis, use the active voice.

"A criminal organization has created this virus."
(Agent is emphasized)
3. Present Perfect Passive Rule

Passive is rarely used with present perfect continuous. Use passive present perfect instead!

"More videos have been posted to the Internet."
(Not 'have been being posted')
