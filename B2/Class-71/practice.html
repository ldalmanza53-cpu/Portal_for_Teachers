Unit T-89 • Section 2 Grammar

Present Unreal Conditionals with unless, only if, and even if

Use present unreal conditionals to talk about imaginary situations. Notice how each connector shifts the meaning:

unless = except if

Exceptions to Decision

Specifies an exception that alters the hypothetical action.

"I wouldn't try to return it unless it were a large amount."
only if = strictly on condition

Strict Conditions

Stresses that the result happens under only one specific condition.

"I would keep it a secret only if I liked my co-worker."
even if = regardless of

Unexpected Results

Shows that the result will occur regardless of the extreme condition.

"Even if I were really broke, I'd give the money to the police."
