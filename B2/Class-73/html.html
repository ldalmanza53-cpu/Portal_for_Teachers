Grammar Focus • Page T-147 Unit 11A

Shortened Conditionals: If so & If not

To ask follow-up questions after a yes/no question, English speakers use shortened conditionals to avoid repeating the full clause.

Positive Follow-Up: If so, ...

Replaces the positive condition ("If you would / If you do"):

🗣️ "Would you consider lying to a friend to avoid hurting their feelings?"

➡️ "If so, what kinds of things would you lie about?"

(Meaning: If you would consider lying...)

Negative Follow-Up: If not, ...

Replaces the negative condition ("If you wouldn't / If you aren't"):

🗣️ "Are you sure your friends are loyal and trusting?"

➡️ "If not, you shouldn't tell them your secrets."

(Meaning: If you are not sure...)

Follow-Up Question Generator
