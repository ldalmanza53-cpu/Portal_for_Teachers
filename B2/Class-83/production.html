Mixed Conditional Structures

2 Core Patterns for Travel Analysis

Pattern 1: Past Cause -> Present Result If + Past Perfect (had + V3) → Would + Base Verb (now)
"If I had bought a water-resistant jacket, I wouldn't be soaking wet right now."
Pattern 2: Present Trait -> Past Action If + Past Simple (were/knew) → Would Have + V3 (past)
"If you were a more open-minded traveler, you would have tried local street food yesterday."
