How are things back in Cartagena? Are you glad to be home again? Sorry I haven't written lately. I have a lot of new responsibilities at work now, so I've been really stressed. My job didn't use to be so demanding!

Anyway, the weekend will be here soon, so I'm sure I'll feel better then. Write soon!

Annie

Grammar Masterclass • Page T-75

Past Habitual: Used to vs. Would

Both used to and would express past repeated habits that are no longer true. However, stative verbs have specific restrictions!

Dynamic Action Verbs (Accept Both)

Actions that were repeated regularly in the past can use either used to OR would.

✔️ "We used to sit around talking."

✔️ "We would sit around talking."

✔️ "I would see a great jacket at the mall."

Stative Verbs (ONLY Used To!)

Stative verbs (states of being, thoughts, feelings, possession: live, be, have, like, think, know) CANNOT use would.

✔️ "You always used to make me laugh."

✔️ "My job didn't use to be so demanding!"

❌ "My job wouldn't be so demanding!" (Incorrect)
