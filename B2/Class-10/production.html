Core Methodology

The 4-Step Pre-Writing Framework

Why write immediately when you can plan first? Follow these 4 structured steps before drafting any proposal.

STEP 01

1. Define Core Problem

Clearly articulate *what* challenge exists without jumping straight to conclusions.

"The main issue we face is..."
STEP 02

2. Root Cause Analysis

Ask "Why?" multiple times to uncover underlying drivers rather than superficial symptoms.

"This problem is caused by..."
STEP 03

3. Solution Brainstorm

Generate multiple solutions without judging, then group ideas into logical clusters.

"One effective solution is to..."
STEP 04

4. Structured Outline

Organize your clustered points into a clear proposal skeleton (Problem -> Causes -> Solutions).

"Firstly... Consequently..."
Language Matrix

B1 Target Problem-Solving Vocabulary

Use these sentence starters during ideation and in your proposal outline.

1. Problem Statements

  • • The core issue facing us is...
  • • Recent data highlights a critical challenge in...
  • • Our main bottleneck involves...

2. Root Cause Starters

  • • This issue is primarily caused by...
  • • A key factor is due to...
  • • This challenge stems from...

3. Solution Starters

  • • One effective solution is to...
  • • To resolve this, we should...
  • • In order to mitigate this, we can...

4. Linking & Outcomes

  • • Firstly... Secondly...
  • • Consequently, this will reduce...
  • • As a result, productivity will...

Unplanned Hasty Draft vs. Pre-Written Proposal Comparison

See why organizing ideas before writing creates superior business and academic proposals.

Feature Unplanned Hasty Writing (Avoid) Pre-Written Structured Proposal (Target)
Structure Disorganized sentences mixing problems and solutions randomly. Clear flow: Problem -> Root Causes -> Primary Solution -> Outcomes.
Cause Analysis Blames surface symptoms without addressing why they happen. Uses clear connectors ("primarily caused by", "stems from").
Solution Clarity Vague suggestions ("we should fix it") with no concrete steps. Actionable steps with linking markers ("firstly", "consequently").
