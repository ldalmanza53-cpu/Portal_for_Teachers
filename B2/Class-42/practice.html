Exercise B Grammar Preparation

Participle Modifiers & Opinion Structures

Master reduced clauses like "movies set in the future" and "stories based on books".

B1 Key Rule:

Notice how we drop "that are / which are":

movies [which are] set in the past

1. Participle Modifiers

  • set in [time/place]: "I like movies set in the future / set in New York."
  • based on [books/true events]: "I prefer stories based on books / based on real life."

2. Expressing Preferences & Reasons

  • I love... so I really liked...: "I love dramas, so I really liked The Great Gatsby."
  • In my opinion / It's more fun to: "In my opinion, sci-fi is the best because it's more fun to imagine."
