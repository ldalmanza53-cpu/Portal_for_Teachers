📖 ReportTalk Reference Handbook

1. Public Behavior Terminology

  • Spatial Awareness: Consciousness of physical personal space boundaries in crowds.
  • Loudspeaker Etiquette: Using audio headphones in public transit instead of external speakers.
  • Oblivious to: Unaware of how personal noise or behavior disturbs nearby people.
  • Commandeer Seats: Unfairly occupying extra seats with bags or feet.

2. Complete Tense Backshifting Matrix

Present Simple → Past Simple
Present Continuous → Past Continuous
Present Perfect → Past Perfect
Will / Can / May → Would / Could / Might

3. Time & Place Deictic Shifts

here → there
now → then
today → that day
tomorrow → the next day
yesterday → the day before
this → that

4. Reporting Verb Preposition Frames

• Verb + that + Clause: complain, explain, retort, admit, claim, state

• Verb + Object + to + V1: urged, warned, advised, ordered, reminded

• Verb + Preposition + -ing: accused of, apologized for, insisted on, congratulated on
