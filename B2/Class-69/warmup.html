Grammar Architecture

The Anatomy of Indirect Questions

When describing problems politely, direct questions shift into statement word order (Subject + Verb).

1

Statement Word Order

Unlike direct questions, indirect questions use standard Subject + Verb order. No inversion occurs!

❌ ...why is the server down?

✅ ...why the server is down.

2

Remove Auxiliary "Do / Does / Did"

Drop auxiliary verbs (do, does, did) and conjugate the main verb according to the tense.

❌ ...why does the engine stall?

✅ ...why the engine stalls.

3

Use "If / Whether" for Yes/No

If the direct question lacks a question word (Wh-), introduce the clause using if or whether.

❌ Direct: "Is the printer jammed?"

✅ Indirect: "...if the printer is jammed."
