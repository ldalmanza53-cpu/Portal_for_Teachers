B1 Grammar Guide: Capability, Function & Possibility

Expressing what things can do, how they are repurposed, and what alternatives exist using B1 structures:

Capability & Function Patterns
  • • could be used for + [verb]-ing: A binder clip could be used for organizing cables.
  • • can serve as a + [noun]: A cut bottle can serve as a handy funnel.
  • • functions as + [noun]: A rubber band stretched over paint functions as a wiper.
  • • if you [verb], it allows you to [verb]: If you add a magnet, it allows you to pick up dropped screws.
Alternatives & Adjectives
  • • Instead of buying X, you can Y: Instead of buying a phone stand, you can clip two binder clips together.
  • • Key Innovation Adjectives: versatile, flexible, lightweight, durable, clever, handy, practical, eco-friendly.
