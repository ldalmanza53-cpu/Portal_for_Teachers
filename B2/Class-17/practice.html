Learning Objectives (CEFR B1)

Defining Relative Clauses

Identify necessary information using that, who, when, where (e.g., "People who live in cities have more stress...").

Non-Defining Relative Clauses

Add extra non-essential details enclosed in commas using who, which, where (e.g., "New Yorkers, who are huge baseball fans, have two pro teams...").

Grammar Focus: Defining vs Non-Defining Relative Clauses

Defining Clauses: Necessary info. Uses that, who, where, when. No commas!
"Pamplona is that city in Spain where the bulls run through the streets."
Non-Defining Clauses: Extra info enclosed in commas! Uses who, which, where. NEVER use that!
"Cairo, which has fascinated Europeans for ages, draws countless tourists."
